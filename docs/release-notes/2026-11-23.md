# Turn 16 Release Notes — Nov 16–22, 2026

Weekly digest compiled from merged pull requests and closed issues in `HandsUpBilly/BBT`.

**11** PRs merged (5 shipped to production `main`, the rest to `staging`) · **4** issues closed

A behind-the-scenes week focused on the Puzzle Editor. Puzzle edits are now saved as private drafts and only reach players when an admin explicitly publishes them, so the puzzles you play stay stable while new content is being worked on. Editor content is now versioned and synced with GitHub, with conflict protection, history and rollback, and admins can preview exactly which puzzles go into a GitHub export. Nothing changed in gameplay, and all existing puzzles, series and leaderboard scores are preserved.

## New

- **Save Draft and Publish for puzzles and series.** Saving in the Puzzle and Series Creators now stores a private draft. Players keep seeing the last published version until an admin chooses **Publish Draft** (or **Unpublish Draft**), with a confirmation step and checks that stop two editors from overwriting each other. Existing content was upgraded in place and stays published. ([#389](https://github.com/HandsUpBilly/BBT/pull/389), [#385](https://github.com/HandsUpBilly/BBT/pull/385), closes [#377](https://github.com/HandsUpBilly/BBT/issues/377))
- **Versioned editor content with GitHub sync.** Every puzzle and series now has a revision history, with rollback and a sync status display. Edits made in the editor and changes deployed from GitHub are merged safely, and any real conflict is shown rather than silently overwritten. ([#384](https://github.com/HandsUpBilly/BBT/pull/384))
- **Pick and preview what goes into a GitHub export.** Before an admin exports editor changes to GitHub, a read-only preview lists every candidate with its own checkbox (none pre-selected) and flags conflicts. The admin then confirms the exact filenames, so unrelated unpublished drafts never slip into an export. ([#388](https://github.com/HandsUpBilly/BBT/pull/388), [#387](https://github.com/HandsUpBilly/BBT/pull/387), closes [#386](https://github.com/HandsUpBilly/BBT/issues/386))

## Fixed

- **Series assignment error and publish safety.** Fixed a crash when adding puzzles to a series through the older series-assignment path. Publishing now always requires a verified administrator, even on development setups that otherwise allow open editing. ([#391](https://github.com/HandsUpBilly/BBT/pull/391), [#390](https://github.com/HandsUpBilly/BBT/pull/390))

## Breaking

- **Saving no longer publishes immediately (admins only).** Puzzle and series authors now have to press **Publish** after saving, because a save on its own no longer changes what players see. Regular play is unaffected. ([#389](https://github.com/HandsUpBilly/BBT/pull/389))
