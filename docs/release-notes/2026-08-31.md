# Turn 16 Release Notes — Aug 24–31, 2026

Weekly digest compiled from merged pull requests and closed issues in `HandsUpBilly/BBT`.

**31** PRs merged · **4** issues closed · **v1.0.1** shipped

The heaviest week since launch: a full visual rebrand to Turn 16, a redesigned sign-in and tutorial experience, and a new way to get in touch — alongside a run of layout fixes on the review and drill screens.

## New

- **Turn 16 branding, top to bottom.** The app now carries a proper wordmark and logo — on the sign-in screen, the home masthead, the in-game HUD, the About dialog, and the footer — instead of plain text labels. ([#239](https://github.com/HandsUpBilly/BBT/pull/239), [#250](https://github.com/HandsUpBilly/BBT/pull/250), [#248](https://github.com/HandsUpBilly/BBT/pull/248))
- **Redesigned sign-in screen.** The centered login card is now a split-screen "tunnel" gateway with new pre-match artwork. Google sign-in, guest entry, and alias selection all still work the same way. ([#242](https://github.com/HandsUpBilly/BBT/pull/242))
- **Contact Us.** A general "Contact us" option now sits in the account menu alongside Help and Settings — open to guests, no sign-in required. Messages go out by email with your reply address attached, or you can send anonymously if you'd rather not be replied to. ([#244](https://github.com/HandsUpBilly/BBT/pull/244), [#249](https://github.com/HandsUpBilly/BBT/pull/249))
- **Choose your board size.** Settings now has a Small / Medium / Large board-size control. The old Zoom button, which players reported as broken, has been removed — Large scales the pitch up and scrolls instead. ([#233](https://github.com/HandsUpBilly/BBT/pull/233), closes [#228](https://github.com/HandsUpBilly/BBT/issues/228))
- **Tutorial guidance now explains itself as you play.** The Tutorial coach no longer blocks you with scripted, full-screen steps. Instead it offers compact, in-context explanations next to the action menu, tracks which concepts you've seen or used, and lets you jump straight to any drill from a chooser. ([#227](https://github.com/HandsUpBilly/BBT/pull/227), [#252](https://github.com/HandsUpBilly/BBT/pull/252))
- **Free Play match filters.** Free Play now has an All matches / Series / Specials filter bar, and each match card shows a clear badge for where it came from. ([#251](https://github.com/HandsUpBilly/BBT/pull/251))

## Improved

- **Refreshed look across every screen.** Typography, spacing, and color were unified across the home screen, settings, and in-game HUD as part of the Turn 16 visual foundation, with a consistent red accent replacing a mix of ad-hoc styles. ([#235](https://github.com/HandsUpBilly/BBT/pull/235), [#237](https://github.com/HandsUpBilly/BBT/pull/237), [#232](https://github.com/HandsUpBilly/BBT/pull/232), [#238](https://github.com/HandsUpBilly/BBT/pull/238), [#240](https://github.com/HandsUpBilly/BBT/pull/240))
- **Clearer parallel-universe review.** The post-match branch review is wider on desktop, with a clearer header for each universe and outcome, and the move list is now a numbered decision log leading to the final probability. ([#255](https://github.com/HandsUpBilly/BBT/pull/255), [#241](https://github.com/HandsUpBilly/BBT/pull/241), [#231](https://github.com/HandsUpBilly/BBT/pull/231))
- **Final tutorial drill rewritten for how Blocks actually work now.** The last drill's lesson text and diagram were rewritten to match the current auto-branching Block system, showing how outcomes split into parallel universes and how Lockstep merges the equivalent ones back together. ([#230](https://github.com/HandsUpBilly/BBT/pull/230))

## Fixed

- **Stray "Sign in as…" card no longer appears.** A floating Google account card that looked misaligned next to our own sign-in buttons was actually Google's own auto-prompt, triggered by a background re-login check. That check has been removed; signing in and staying signed in both still work exactly as before. ([#247](https://github.com/HandsUpBilly/BBT/pull/247))
- **Oversized Game Branches diagram.** The branch tree on the run-complete summary screen was stretching to fill the panel, blowing up small diagrams to several times their intended size. It now renders at its natural, compact size and only scrolls when it's genuinely wide. ([#253](https://github.com/HandsUpBilly/BBT/pull/253))
- **Misaligned drill cards and hidden dice count.** Play/Replay buttons on the Tutorial drill chooser now line up across a row regardless of description length, and the dice-count label on the block outcome strip no longer scrolls off-screen on narrow phones. ([#256](https://github.com/HandsUpBilly/BBT/pull/256))
- **Home hero seam and artwork proportions.** A stray vertical line down the center of the home hero has been removed, and the hero artwork keeps its correct proportions on wide screens instead of stretching. ([#254](https://github.com/HandsUpBilly/BBT/pull/254), [#249](https://github.com/HandsUpBilly/BBT/pull/249))
- **Compact mobile HUD spacing.** The compact HUD used on narrow phones no longer reserves empty space for a caption band that only the desktop layout uses. ([#229](https://github.com/HandsUpBilly/BBT/pull/229))

## Breaking

None this week that changes existing behavior in a way that needs action from players.

**Also this week:** version 1.0.1 was released and deployed; an admin-console route for removing managed administrators was fixed in local development (production was unaffected — [#221](https://github.com/HandsUpBilly/BBT/issues/221) / [#224](https://github.com/HandsUpBilly/BBT/pull/224)); and several internal-only PRs landed — test coverage, dead-code cleanup, and documentation fixes ([#225](https://github.com/HandsUpBilly/BBT/pull/225), [#226](https://github.com/HandsUpBilly/BBT/pull/226), [#229](https://github.com/HandsUpBilly/BBT/pull/229)) — with no visible effect on the app.
