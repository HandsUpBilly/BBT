# Turn 16 Release Notes — Sep 7–13, 2026

Weekly digest compiled from merged pull requests and closed issues in `HandsUpBilly/BBT`.

**16** PRs merged · **5** issues closed

A week focused on admin tooling and puzzle authoring: admins can now promote or demote other admins right from the login records, admin-only puzzles and series are clearly tagged everywhere they appear, puzzle authors can restrict which actions are available in a scenario, and a new Crowd Surf objective joins Touchdown as a way to win. Alongside that, a stat-display bug for BB2025 rosters and an incorrect skill-access bug for Big Guys were both fixed.

## New

- **Promote or demote admins from the login records.** The Statistics player-login table now has Promote/Demote controls, so admins no longer need to know a player's email address to grant or revoke admin access. ([#331](https://github.com/HandsUpBilly/BBT/pull/331), closes [#324](https://github.com/HandsUpBilly/BBT/issues/324))
- **Admin-only puzzles and series are now tagged.** An "Admin only" badge now appears on admin-only rows in the Puzzle and Series Creator libraries, and on the home screen's series and Single Plays selectors, making it clear at a glance which content isn't visible to everyone. ([#327](https://github.com/HandsUpBilly/BBT/pull/327), [#332](https://github.com/HandsUpBilly/BBT/pull/332), closes [#323](https://github.com/HandsUpBilly/BBT/issues/323))
- **Choose which actions are available in a puzzle.** The Puzzle Creator now has toggles for Move, Hand-off, Pass, Block, and Blitz — disabled actions are grayed out in the in-game menu, letting puzzle authors focus a scenario on a specific tactic. Existing puzzles default to all actions enabled. ([#333](https://github.com/HandsUpBilly/BBT/pull/333))
- **Crowd Surf objective.** Puzzles and series can now be won by shoving an opponent off the pitch, including at the end of a chain push, with a dedicated in-game action, its own completion screen, and updated Help copy. ([#330](https://github.com/HandsUpBilly/BBT/pull/330))
- **Download All in the Puzzle Creator.** A new "Download All" button exports every draft puzzle and series as one JSON file, keyed to match the checked-in file layout, for admins reconciling in-progress editor work. ([#315](https://github.com/HandsUpBilly/BBT/pull/315))

## Fixed

- **Wrong stats shown for BB2025 rosters.** Agility and Armour Value targets on player cards, action menus, and the Puzzle Creator were displayed incorrectly, even though the underlying roster data was correct; the display conversion is now fixed and covered by regression tests. ([#325](https://github.com/HandsUpBilly/BBT/pull/325))
- **Big Guys wrongly offered General/Agility/Passing skills.** Trolls and Ogres could be given access to skill categories (like Dodge) they should never have in any Blood Bowl edition; their doubles access is now correctly limited to Mutation only. ([#314](https://github.com/HandsUpBilly/BBT/pull/314))

## Breaking

- **Series-level objectives removed.** Objectives are now set per puzzle only; the Series Creator's objective control has been removed, and any legacy series-level objective value is dropped the next time that series is saved. This only affects series/puzzle authors in the admin Creator tools — regular play is unaffected. ([#329](https://github.com/HandsUpBilly/BBT/pull/329))
